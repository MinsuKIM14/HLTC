# HLTC Tennis

HLTC Tennis는 동아리 복식 경기 운영을 위한 오프라인 안드로이드 앱입니다. Kotlin + Jetpack Compose + Room 기반으로 제작되었습니다.

## 주요 기능
- 홈: 오늘 시작/최근 세션/요약
- 플레이어 관리: 기수/이름/레벨(1~5)/활성 관리
- 세션 생성: 참가자 선택 + 총 게임 수 + 랜덤/밸런스 모드 자동 대진
- 경기 운영: 예정/완료 상태, 스코어 입력, 결과 초기화, 팀 스왑(수동 편집)
- 통계: Completed 경기만 반영한 승패/승률 집계
- 데모 데이터 버튼 제공

## 화면 흐름
1. 홈에서 데모 데이터 입력 또는 선수 등록
2. 세션 탭에서 참가자 선택, 총 게임 수/모드 선택 후 세션 생성
3. 경기 리스트에서 결과 저장 또는 초기화, 수동 팀 스왑
4. 통계 탭에서 누적 승률 확인

## Android Studio 실행 방법
1. Android Studio에서 `/workspace/HLTC` 열기
2. Gradle Sync 완료
3. `app` 실행 구성 선택
4. 에뮬레이터/실기기(예: Galaxy S25)에서 Run

## 매칭/편집 규칙
- 매칭 엔진은 **출전 균등**을 최우선으로 4명 후보를 매 경기 선발합니다.
- Random: 팀 무작위 셔플
- Balanced: 팀 레벨 합 차이 최소 조합 선택, 동점 시 파트너 중복 적은 조합 우선
- 통계는 Completed 경기만 반영
- Completed 경기 라인업 수정 전 결과 초기화 필요
